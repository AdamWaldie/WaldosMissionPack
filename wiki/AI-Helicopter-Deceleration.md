# AI Helicopter Deceleration

> **Use this page when:** migrating a mission that previously configured WMP helicopter deceleration.

> **Migration notice:** Helicopter deceleration control moved to the standalone [Waldos AI Tweaks](https://github.com/AdamWaldie/WaldosAITweaks) mod. WMP no longer loads or configures this controller.

Existing missions should remove WMP-specific calls for this feature and configure the addon instead.

| Previous WMP interface | Type | Current status |
| --- | --- | --- |
| Helicopter deceleration setting or script call | Removed controller | Use Waldos AI Tweaks when approach deceleration is required. |
