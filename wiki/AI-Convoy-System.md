# AI Convoy System

> **Use this page when:** migrating a mission that previously called WMP's convoy controller or placed its Zeus convoy module.

> **Migration notice:** Convoy control moved to the standalone [Waldos AI Tweaks](https://github.com/AdamWaldie/WaldosAITweaks) mod. WMP no longer registers the convoy function or Zeus module.

Existing missions should remove WMP-specific calls for this feature and configure the addon instead.

| Previous WMP interface | Type | Current status |
| --- | --- | --- |
| Convoy script call or Zeus module | Removed controller | Use Waldos AI Tweaks when convoy control is required. |
