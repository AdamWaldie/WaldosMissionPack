# Teleportation and aircraft boarding

> **Use this page when:** following an older link to WMP's player-movement helpers.

These calls set up different actions:

- [Teleport action](Teleport-Actions) moves a player to a marker, object, location, group or task.
- [Aircraft boarding action](Aircraft-Boarding-Actions) puts a player into a live aircraft's cargo seat.

For a named network of save, heal, spectator and travel points, use [Base Services](Base-Services).
